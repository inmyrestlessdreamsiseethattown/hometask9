# Лабораторная работа №9

## Вариант 16 — Четырёхугольник

### Условие задачи

Написать программу на языке C, выводящую на экран геометрическую фигуру с помощью символа, заданного пользователем с клавиатуры.

Согласно варианту 16 необходимо вывести контур четырёхугольника с окружностью внутри. Параметр фигуры — радиус `r`.

### Входные данные

- `ch` — символ, которым рисуется фигура.
- `r` — радиус окружности.

### Алгоритм работы

1. Ввести символ для рисования.
2. Ввести радиус окружности.
3. Проверить допустимость радиуса.
4. Определить координаты вершин четырёхугольника.
5. Для каждой точки экранной сетки определить, принадлежит ли она контуру четырёхугольника или окружности.
6. Вывести символ в найденных точках, а в остальных — пробел.
7. Завершить программу.

### Используемые функции и операции

- `printf()` — вывод информации на экран.
- `scanf()` — ввод данных с клавиатуры.
- `sqrt()` — вычисление квадратного корня.
- `fabs()` — вычисление абсолютного значения числа.
- `for` — организация циклов.
- `if` — проверка условий.

### Проверка программы

Пример входных данных:

```text
*
4
```

Здесь `*` — символ рисования, `4` — радиус окружности.

Программа выводит контур четырёхугольника и окружность внутри него, используя введённый символ.
